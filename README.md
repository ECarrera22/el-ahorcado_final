## Descripción del Proyecto
Este proyecto consiste en el desarrollo de un juego interactivo en consola llamado "Ahorcado Educativo", enfocado en palabras relacionadas con tecnología, sociedad y futuro.

El objetivo es integrar los conocimientos adquiridos en las cuatro unidades de la asignatura, aplicando estructuras fundamentales de programación en Python.

---

## Objetivo
Visualizar el impacto de las nuevas tecnologías en la sociedad mediante un juego educativo interactivo desarrollado en consola.

---

## Funcionalidades
- Menú interactivo en consola  
- Selección de categoría  
- Selección aleatoria de palabra  
- Validación de entrada del usuario  
- Control de intentos  
- Sistema de letras correctas e incorrectas  

---

## Estructuras Aplicadas

### Listas
Se utilizan listas para almacenar palabras por categoría y letras incorrectas.

### Diccionario
Se utiliza un diccionario para organizar las palabras por categorías.

### Tupla
Se utiliza una tupla para la configuración del juego (número de intentos y versión).

### Funciones
El programa está dividido en funciones para modularizar el código:
- mostrar_menu()
- seleccionar_categoria()
- elegir_palabra()
- validar_letra()
- jugar()

### Estructuras de Control
- if / elif / else
- while
- for
- random.choice()

---

## Cómo Ejecutar el Programa

Desde la carpeta principal ejecutar:

python src/main.py
